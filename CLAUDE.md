# jjfanwars: notes for Claude

Browser war game in one file: `index.html` (Three.js r170, inlined: the ESM build converted to a classic script that sets `window.THREE`). Live at https://jjfanwars.github.io. Repo: `jjfanwars/jjfanwars.github.io`. The game was formerly called KICwars, and the repo was formerly KicWars/kicwars.github.io.

## Rules for every change
- **Privacy:** the repo is public. Never commit the owner's name, usernames, email, location, secrets (ADMIN_KEY, tokens) or chat details. Refer to them as "the owner". Relay secrets live only in Cloudflare.
- Copy `index.html` to `warsim.html` before each commit.
- Commit messages have no Co-Authored-By, Claude-Session or other Claude attribution lines (the user asked for none).
- Push with `git push -q origin main`. Make sure origin points to `https://github.com/jjfanwars/jjfanwars.github.io`. Leave nothing uncommitted or unpushed.
- Don't open PRs unless asked.
- Add a line to the in-game **What's new** list (`CHANGELOG` array near the end of index.html, newest first) for user-visible changes.
- What's new must never mention the site or repo move, and never reveal the `tester` code (it unlocks everything; the code box is at the bottom right of the menu).
- The user wants concise replies and "quick" versions when asked.
- Don't run long simulations. Write the code first, then do a load check and short Playwright pokes.

## Testing
- Playwright in headless Chromium, for example `UI.launch({mode:'host',size:128,seed:1,players:[{nation:0,name:'You'},{nation:1,name:'Bot',bot:'easy'}],me:0,link:null,tut:false,quick:false})`.
- To start arcade battles: `UI.openBat('arc'); UI.batLaunch(i); UI.scenPick('f16')`.
- Headless runs at very low fps. To test physics, call `Direct.movePlane(1/60, e, M, N)` in a loop instead of waiting for frames.
- Syntax check: extract each `<script>` block and run `node --check` on it.

## Code map (all in index.html)
- **Script blocks:** Sim (host-authoritative, DT .1), Renderer, Direct (first-person control of any unit), UI, Sfx, Tension (death screen).
- **Events and commands:** events go through `this.ev({k})`, reach `Renderer.handle` and the `UI.onEvent` switch, and Direct gets them too. Commands go through `g.issue({c})` and land in the `Sim.prototype.issue` switch.
- **Data tables:** NATIONS, UNITS, BUILDINGS, PWPN (per-unit weapons for Direct; index = weapon slot), BATTLES (`arc:'air'|'ground'` arcade modes), TIERS, RANKS, XP, Stats (localStorage `kw-xp` and `kw-stats`), BIND_DEFAULTS and BIND_LABELS.
- **Arcade:** `arcSetup`, `arcStep`, `arcSpawn(o, k, rwy)`, `arcTankGoal` (tank bots use a lane plus a push/flank/over role), `scenSpawn(pi, k, tier, rwy)`. `S.field[o]` is the arcade airfield.
- **Planes (Direct):**
  - `movePlane` holds the flight model.
  - `groundRoll` handles takeoff and ground roll; touchdown is detected in movePlane; `nearField`.
  - `this.landing` is the landing mode; `this.vLock`/`leadAim` is the WT camera target lock (L or right click).
  - `drawAirMarks` draws range markers, off-screen arrows and the lead circle.
  - The missile seeker uses `SEEKER` with `Sfx.lockTone`; `bsight` is the bombsight (Q for bombers).
- **Weapon keys:** E fires W[1], R fires W[2], Y fires W[3] (`w4`); K or middle click spots.
- **Spies:** questions in SPY_GUARDS (exactly 2 per nation) plus the shared card (leader, password, war cry).
  - Questioning cutscene: `startCut`.
  - Heists: `spyTarget`, `startHeist`, `heistStep` on the client; `Sim.spySteal` on the server.
  - `p.spyMap` holds the buildings a spy has mapped.
- **Damage reports:** `hurt()` logs `hitLog`, which flushes as a `dmgrep` event.
- **RTS UI:**
  - `groups`/`groupBar`/`selGroup`, `formation` (right-drag).
  - Clickable bad alerts; Space jumps to the last alert.
- **Sound:**
  - `Sfx.init` runs on the first input.
  - `Sfx.engine(kind, k)` and `Sfx.lockTone(st, k)` fade out if not called every 300 ms.
  - Menus are silent (`Sfx.ui` is a no-op), and the demo battle is muted (`Sfx.mute`).
- **Touch:** `Direct.isTouch` is decided by the last real input (`window.__ptr`); touchscreen laptops get mouse lock.
- **Accounts:** `Acct` (next to `Profile`) signs in by username only, syncs `kw-xp`, `kw-stats`, `warsim-camp` and settings with the relay's `/acct/login|save|logout` (class `Accts`, SQLite Durable Object in relay/worker.js). `kw-owner` = account that owns the local save. Menu bar `#acctBar`. Test locally with `npx wrangler@3 dev` in relay/ and `?relay=ws://127.0.0.1:8787` (Chromium needs `--no-proxy-server`).
- **Tracker:** `Track` (next to `Acct`) sends anonymous hits (random `jjf_uid` per browser; open with device + browser, beat every minute while visible, play with a mode label from `Track.mode(o)` in `UI.launch`, end with win/loss and length from `showOver`) to relay `/track/hit` (class `Track`, SQLite, days in the TZ secret's zone, else UTC). `/track/sum?days=N` feeds `stats.html` (charts: players per day, play time, games, peak online, hour of day, session length, days played, devices, browsers, modes with finish/win rate; also account and live room counts). Opening `/track/sum` or `/stats` on the relay in a browser redirects to stats.html; `?json` shows the raw data. `?notrack` turns it off.

- **jjfront (`front.html`, 10 Nov 2026):** separate OpenFront-style territory game, live at /front.html. Own file, own `<script id=sim>` (pure deterministic `Sim`: only + - * / sqrt and a seeded PRNG, so no Math.random/pow) and `<script id=app>` (menu, lobby, relay net, canvas render, input). Deterministic lockstep: the host (or solo player) stamps intents into a numbered turn every 100 ms, the relay forwards it, every client steps the same sim; host sends a state hash every 100 turns (`G.desync`). Uses the existing relay unchanged; room names start with `[Front]`. Rules follow OpenFront (AGPL-3.0, keep the visible credit line and header). Buildings: 1 city, 2 post, 3 port, 4 capital (free at spawn, +50k troop cap, capture = +150 gold and -30% troops for the loser), 5 silo, 6 SAM. Nukes: `NUKE_COST` 400, 4 s flight, radius 5 clears land and buildings, SAMs (12 tiles, 70%, 30 s reload) can intercept; AI nations build silos/SAMs and nuke leaders (`botNuke`). Client: relief-lit terrain in `initMap` (`BASE`, must stay a clamped array), conquest flashes (`flash`/`fl`), `icon`, `drawNukes`, minimap, `TOOLS` (keys 1-6). Alliances: intents `ally` (propose, or accept if they asked), `decline`, `break` (-25% troops, `traitor` 2 min), `give` (20% troops / 25% gold); allies cannot attack each other; leader plus allies reaching 70% is a team win (`over.team`); `botDiplo`. Chat: intent `chat` (sanitized, 1/s) lands in `sim.log` with `chat` = player id. Boats: `Sim.boat` (BFS over water from any of your shores, max 140 tiles), `stepBoats` (1 tile per 2 turns, enemy port within 8 tiles sinks 15%/s), `landBoat` creates an attack with `free:1` (first tile skips the adjacency check); atk intent falls back to a boat when there is no land contact, `boat:true` forces it (B key / Shift+click). Terrain option `cfg.isl` (islands, `terr.c` = landmass ids, `comp`); `botBoat` sends AI nations to other landmasses. AI nuke cooldown is 2.4x the human one (pacing: AI-only games end in about 12-35 min). Real maps: `MAPS` (10 maps from OpenFront's `map16x.bin`, CC BY-SA 4.0, downsampled to about 260 wide, RLE + base64, 5 elevation levels; `realMap`, selected by `cfg.map`, dims come from the map; regenerate with a small script over `resources/maps/*/map16x.bin`: byte = land bit 7, elevation bits 0-4, 31 = impassable). Roads: `Sim.road` tile flags, intent `road` (BFS over own land, 4 gold per new tile, max 90), +0.04 gold/s each, attack cost x0.7 next to your road (`supplied`). Factory (bld 7): +4 gold/s, +4 more when `linked` by road to a city/port/capital (`facOk`, refreshed every 5 s). Ships: `Sim.ships` (`trade`: port to port by water BFS, pays both owners; `war`: built at a port, max 4, auto-hunts non-allies within 14 tiles, captures trade ships, sinks transports, 25 dmg to warships, shells coast troops, takes 8/6 dmg per second from enemy ports/posts within 8, heals at own port); intents `ship` and `fleet` (rally water tile); max 3 route searches per turn (`bfs`). Fallout: `Sim.fall` expiry ticks, conquest cost x2.5 for 90 s after a nuke. Random events every 3-5 min (`event`: plague on the leader, gold rush, harvest, relief for the smallest). Sound: sim pushes codes to `sq` (not hashed), client plays them with `Sfx` (WebAudio synth, mute button, `jjf-front-snd`). Tools 1-9,0 map to `TOOLS`. Spawn phase `SP` is 100 turns (10 s). UI follows FrontWars' layout (looked at frontwars.io, a commercial OpenFront-derived game; copy the look, never their assets): table leaderboard `#lb` (rank, owned, gold, troops, ally buttons), `#stat` (troops with growth rate, gold, attack ratio, boat), numbered hotbar `#bld` in `#bar`, events panel `#evp` (feed, my attacks, chat box), top-right `#topR` (icons, timer `#top`, minimap), orange accent `--accent`; territories are translucent fills with a thin outline, labels small and white; real-map elevation is 3x3-smoothed in `realMap`. **Economy rework (11 Nov 2026, supersedes the older numbers above):** modelled on OpenFront's `EngineConfig.ts` / FrontWars. Capitals, the road tool and the flat factory income are gone (road/`supplied` code is still in the sim but unused). Gold is raw and flat: 250 per turn (OpenFront 100, x2.5 for shorter games), tribes 125, start 0, plus conquest gold (all of a bot's gold, half of a human's) and trade/train income. Prices (`buildCost`, `p.lvl[b]` = level sum per building type): city 125K doubling to 1M; factory and port share one doubling counter (125K to 1M); defense post (n+1) x 50K up to 250K; silo 1M; SAM (n+1) x 1.5M up to 3M; warship (n+1) x 250K up to 1M; atom bomb 750K, hydrogen bomb 5M (radius 10, SAM chance 40%), MIRV 25M + 15M per earlier MIRV (9 warheads over the target player's land, radius 3, SAM 25%). Cities give +250K troop cap per level. Clicking an own city/factory/port/silo/SAM with its tool upgrades it (`lvl[i]`, max 9, shown as a badge). Factories spawn trains (`stepTrains`, rate from OpenFront `trainSpawnRate`) that visit up to 5 stations (cities, ports, factories, any owner, same landmass, within `TRAIN_RANGE` 40) and pay per stop (yours 1.5K, ally 5K, other 3.5K; the station's owner is paid too). Trade ships pay both ports 8K + 450 per tile (max 60K). 5 s spawn immunity after the spawn phase (`IMMUNITY`), win at 80%, `GROW` 0.065. Hotbar order as FrontWars: 1 city, 2 factory, 3 port, 4 defense post, 5 silo, 6 SAM, 7 warship, 8 atom, 9 hydrogen, 0 MIRV; F or right-click on water moves the fleet. Test: extract each script and `node --check`; sim is runnable in a `vm` context (give it an `atob`).

- **jjdrop (`drop.html`, 11 Nov 2026, reworked as urban CQB, then multi-storey + online + Siege):** separate first-person urban combat game in body-cam style, live at /drop.html, linked from jjfront (menu button, in-game `#dropBtn` passes `?squad=&foe=`; `?mode=siege` also works). Test hook: open with `?test` for `window.__D`; headless Chromium needs `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`; for logic-only tests stub `requestAnimationFrame` (`addInitScript`) and call `__D.step(1/30)` in a loop, it runs thousands of steps per second that way.
  - **World:** 3x3 city blocks of 76 m on a 96 m pitch, 20 m streets (`BC`, `RDS`, `HALF` 154), perimeter wall. `building()` makes real storeys: up to `MAXF` 4 enterable (`nf`, default 3, Bravo 4, Alpha 1), slabs with stairwell holes (`hole<k>`), a corner stair core (two columns, switchback, `STAIRS`, steps are solids), partitions that avoid the core with a door in every stretch (`segDoors`), exterior doors shifted away from partition ends. Floors above `nf` are a visual mass. Furniture from `furn()`. Geometry is merged per material (`addBox`, `texMat` + `flatMat`); shadows baked (`needsUpdate` after `buildWorld` and after a breach). `SOLIDS` `[x0,x1,z0,z1,top,bottom]` in an 8 m hash `SG` (`blocked`, `hitSolid`, `los`, `standY` steps up to 1.2 m, `pushOut`). Fall damage above about 3 m.
  - **Dynamic pieces:** door leaves (`DLEAF`, open on proximity, `stepDoors`, `setLeaf`; `navRect` restores each leaf to its `d.o` state), siege wall panels (`PANEL`, 2.4 m chunks of the lower 2.4 m, soft or hard, built only when `o.siege`, solids carry `.pan`; intact panels share one merged textured mesh `PANM` rebuilt by `panRebuild` when `panDirty`), openings (`OPEN`) for barricades (`BAR`, plank groups, `barAdd`/`barBreak`, solids carry `.bar`), `reinforce` (steel plate group), `breachPanel`, `melee`.
  - **Destruction:** a soft panel that takes damage gets a cell grid (`CW` 0.2 m, `p.cells`, `p.nc`/`p.nr`); `panHit(p, x, y, z, rad)` removes cells (rad 0 = the one cell), `cellsGone` queues a rebuild (`cellQ`, `panMesh` merges runs of cells, cut edges darker via `addBox(..., cs, ax)`), sends `cl` events, sets `p.open` when a gap 3 cells wide and 1.8 m tall exists (nav then ignores the panel) and breaches the panel under 10% left. `blocked`/`hitSolid` let points through missing cells, `pushOut` lets bodies through via `panGap` (slides toward a nearby gap). Bullets go through up to two soft walls or barricades (x0.62 damage each, `W.cell` chance to knock out a cell), shotgun pellets chew holes, melee and the hammer punch big ones, explosions use `blastWalls`. Debris `chunks`.
  - **Navigation:** 1 m grid with `NL` layers (one per storey), `NAV`, `LINKS` for stairs (each link carries `via` points on the stair centreline), `findPath(sx,sz,sk,gx,gz,gl)` returns `[x,z,layer]` points, `layerOf`, `flood` (building points `b.pts` are only reachable ones), `navRect` after a breach.
