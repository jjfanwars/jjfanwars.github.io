# Black Hollow (`hollow/`): notes for Claude

Read `CLAUDE.md` first (shared rules). Split out of it on 17 Nov 2026; keep this file up to date when you change the game.

- **Black Hollow (`hollow/`, live at /hollow, 17 Nov 2026):** original online co-op survival horror (1-6 players), linked from the jjfanwars menu (`#bHollow`). Built from Whisperpine's code (same world helpers, creature nav, audio synth, HUD overlays) in `hollow/index.html` + `hollow/game.js`. **Net:** own copy of the rally `Net` (no CARS), room prefix `[Hollow]`, `Net.late` (late joiners get `start` with the seed), host id 'H', `Net.relayT = {pose: 1}`. Every client moves its own body and sends `pose` 20 Hz (x/z/y, yaw/pitch, crouch, light, run, `h` = held action key, `hd` hide index, `hb` breath); the host runs the creature, holds, bleed, phases and items and sends `snap` at 15 Hz (`packSnap`/`applySnap`: creature, player status, beacons, cans, taken items, hold progress `hp`, phase/timer, heli, events `ev`). Events go through `emit(e)` -> `applyEv` (down, rev, dead, give, lit, fl, wh, ph, esc, over, snd). Guest actions: `act` {a: pick, can, drop, fl, wh, board, gasp} with the sender's position (`hostAct`). Holds: pose `h` = 'b<i>' (pour fuel, 5 s, must carry a can, near the beacon) or 'r<id>' (revive, 4 s, faster with two); progress in `G.holdP`. Item/can layout is seeded (`WR` from the host's seed), creature randomness `CR`. **World:** 400 m valley (`hills`: fbm + rim mountains), creek `RIVER` carved into the ground (`riverQ`, `waterY`, `wading` slows and makes steps louder; two bridges `BRIDGES`/`bridgeY`), campsite `CAMP` (lit campfire), landing clearing `HELI`, beacons `BEA_POS`/`BEA` (log piles, sign; `FIRES` with flame sprites + 3 pooled lights), buildings via `building()` (ranger cabin with wardrobe + locker, logging shed, chapel shed, outhouse), landmarks (lookout tower, crashed plane, logging camp, cemetery, old mine, stumps/boulders) give `SPOTS` for 7 cans, notes, batteries, flares. **Creature:** Whisperpine's states with multiple targets: senses every hiker (`seesP` adds terrain occlusion `terrClear` and bush cover `inBush`), chase target `M.tgt`, `M.prey` = most isolated hiker (re-picked every 25 s, plus `heat` from noise/light), stalk glimpses before the first beacon, `downPlayer` (drops the can, then the creature flees for `D.down` s), drops to all fours while chasing (`M.four` in `animCreature`). Downed hikers crawl, bleed out after `D.bleed` s; all hikers down for 4 s ends the run. Phases `G.ph` 0 beacons, 1 helicopter inbound (`D.escape` s, hints toward the prey), 2 landed (35 s, E to board within 10 m) -> `endRun`. Remote hikers: `buildHiker` avatars with flashlight beam cones, 5 pooled remote SpotLights, name tags (always for downed teammates), whistle pings (Q, noise 45). Spectate after death/boarding (click cycles). Test hook `?test` -> `window.__H` (`startGame(seed, crew)`, `step`, `hostStep`, `hostAct`, `downPlayer`, `G.forceH` forces the held key). Two-browser tests: mock relay (Node, `wsServer` from playwright-core's `utilsBundle`) + `?relay=ws://127.0.0.1:8787`, stub rAF and alternate `__H.step` on both pages. Not hand-played; online play only tested on the mock relay.

## Polish pass (24 Nov 2026)
- Map (Tab): hiker arrows were mirrored left/right (now `rotate(yaw + PI)`).
- Fuel cans: picking one up now plays a sound and explains what to do (detected locally via `G.hadCan` in `hud`, so it works for guests); X drop gives a thud and a message.
- `gameOver` has a `G.run` token (bumped in `startGame` and `toMenu`): leaving or restarting during the 2.5 s delay no longer pops the old end screen over the menu/new run. The creature's loops (growl, breath, chase drone) fade out once the run ends (`live` factor in `stepFear`).
- Menu shows the fastest rescue per difficulty (`bestLine`, `bh-best-<diff>`); end screen says "new best".
- Helicopter is heard approaching during the last 30 s of phase 1 (rotor panner flies in toward `HELI`, one-time message `G.heliHeard`).
- Hiding muffles the world (master lowpass `A.lp`, deeper while holding breath); distant creature wails `Snd.call` (local per client, `Math.random`, not `CR`, so host determinism is untouched).
- Solo: downed text no longer tells you to crawl to your group. `hud(dt)` objective fade is frame-rate independent.
