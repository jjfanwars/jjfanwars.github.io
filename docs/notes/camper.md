# Camper Crew (`rally/rv.html`): notes for Claude

Read `CLAUDE.md` first (shared rules). Split out of it on 17 Nov 2026; keep this file up to date when you change the game.

- **Camper Crew (`rally/rv.html`, 16 Nov 2026):** co-op first-person road trip in a camper with a walk-in inside, linked from the jjfanwars menu (`#bCamper`) and the Rally menu. Original game in the co-op-vehicle genre (do not copy any specific game's name, art or levels). Reuses the rally engine (`util/stage/tex/world/car/audio/net.js`) plus three files:
  - `js/rvmap.js` (`RVMAP.build()`): one handmade map. Control points `CP` (x, z, road height, tag) -> Catmull-Rom road every 2 m, Hermite height profile (flat over the bridge `deckY` 40 and the ferry `ferryY` 12), coarse IDW height field `cAt` + noise, flat `pads` (farm, logging yard, gas, work site, camp), cliff section (`cliffK`), river (`riverD`, crosses the road at tag `br`), lake (`lakeD`, ferry from `dock0` to `dock1`), `corridor(s, side)` (how far the camper may stray: tight around the puzzles), trees (kinds as rally) and kind-8 brush walls, the fallen log `S.log` (in `S.logs`), winch posts `S.posts`, boulders `S.boulders` (`S.dynNear`), `S.debris`, tow checkpoints `S.checks`, tags in `S.sAll`. Returns a buildStage-shaped object so `Car` and `World.build` work on it (`World.buildProps` is swapped out for the build). `S.decks` holds dynamic surfaces (drawbridge when down, raft) added into `heightAt`; `S.terrainAt` is the ground without them. The grid build takes ~4 s (lattice-accelerated `nearG`).
  - `js/rvbuild.js`: camper layout constants (`FL` floor, `RT` roof, `RVL`: bumper, fuel cap, door, ladder, spare, seats, radio, interior box, furniture AABBs `furn`), `RVSPEC` (car spec passed to `applyCar` as an object), `buildCamper` (exterior, walk-in interior, door leaf, steering wheel, wheels), `buildAvatar`, `itemMesh` (remote, can, tyre, dyn, duck, hook), `sign`, `buildSet` (farm, yard, log mesh, mud tint + puddles, posts, Pete's Gas with a walk-in shop, drawbridge + crank + footbridge, river and lake water, work site + explosives crate, boulders + debris, piers + raft, camp; `S.pbox` = oriented boxes players can't walk through, also given car colliders).
  - `js/rv.js`: host-authoritative. The host (or solo) runs `car` (`hostStep`: driver input from the seat-0 player's pose, winch, pushing, corridor push-back, raft carry, flips, fuel, flats, water -> tow, `stepItems`, `stepHolds`, finish) and broadcasts `snap` at 15 Hz (camper state, items, world state `W`, events `ev`). Every client runs its own body (`ME`: modes `in`/`roof`/`seat` in camper-local coords, `out` in world coords; camper acceleration `RV.aL` throws people about inside and slides them off the roof) and sends `pose` at 20 Hz (relayed to everyone: `Net.relayT = {pose: 1}`; carries `in` drive input, `r` reel, `h` hold key, `pu` push). Guests send `act` (seat, pick, drop/throw, take dynamite, hook ops, horn, quack, radio, tow); `hostAct` applies them. Interactions are built per frame in `targets()` and picked by look direction (`pickTarget`); hold actions (`crank`, `ferry`, `pour`, `tyreN`, `flip`) accumulate in `stepHolds` from every pose's `h`. Winch: hook states stow/held/free/set, cable `LMAX` 42 m, reel with the remote (LMB in, RMB out), tension pulls the camper at the bumper or drags the log as a rigid trunk; too much slack-pull snaps it free. Net: `Net.tag` (room prefix `[Camper]`), `Net.late` (late join gets a `start`). Test hook `window.__CC`; `?solo` starts solo. Headless logic tests: set `__CC.G.on = false` and call `hostStep(1/30)` + `syncRV()` in a loop (a scripted full run reaches camp in ~8 game minutes). Mock relay for 2-browser tests: a small Node server using `ws` from playwright-core's `utilsBundle`.
