# Whisperpine (`night/`): notes for Claude

Read `CLAUDE.md` first (shared rules). Split out of it on 17 Nov 2026; keep this file up to date when you change the game.

- **Whisperpine (`night/`, live at /night, 17 Nov 2026):** original first-person survival horror, linked from the jjfanwars menu (`#bNight`). `night/index.html` (UI, CSS overlays: grain canvas, vignette, fear vignette `#fearV`, wardrobe slats `#slats`, notes, map) + `night/game.js` (everything else, Three.js r170 from `../three-r170.js`, own renderer with ACES, moon shadow refreshed every 6 m, flashlight SpotLight with shadow). World: 340 m square, height grid `HG`/`gH` (matches the PlaneGeometry triangulation), `PADS` flatten camp/buildings/landmarks, `ROAD`, `LAKE`. Buildings via `building(kind, name, x, z, door)` in a local frame (door on local -z, `ROT`, `L2W`/`W2L`), walls in `WALLS` (block player, sight and creature), furniture in `SOL` (player only), `OBST` rects for creature detours, `din/dout/dfront` door points, `hides` (wardrobes/lockers/outhouse) in `HIDES`, item spots `SPOTS`. Geometry is merged per material bucket (`BK`, `lbox`/`wbox`/`put`). Trees: instanced pines/dead trees/bushes in 40 m tiles, collision circles in a hash (`treesNear`). Flow: objectives `G.obj` radio0 -> gen -> fuse -> start -> call -> escape (timer `D.escape`, truck at the gate, win on E). Items (`placeItems`): 3 fuses (spread 38 m), batteries, flares, 5 notes. Creature `M` (`stepCreature`): states roam / inv (noise) / chase / search (checks hide spots with `D.checkP`, `chkT` opening) / stalk (early glimpses, vanishes when watched) / flee (flares within 9.5 m) / kill; `seesPlayer` (range by light/crouch/moving, FOV, walls, `foliage`), `noise(x, z, r, zone)` from footsteps and actions, `plan`/`detour` routing through door points, teleports in behind if too far (after 90 s), hints toward the player in the escape phase. Hiding: E on a wardrobe, hold breath (RMB/Space, 10 s), seen entering = pulled out, breathing within 3.2 m can give you away. Difficulty table `DIFF`. Audio: WebAudio synth (wind, crickets that stop near it, positional growl/breath/footsteps, heartbeat by `P.fear`, chase drone, generator, radio static, truck), radio lines via speechSynthesis (setting `voice`). Settings `wp-set`, best escape `wp-best-<diff>`. Test hook `?test` -> `window.__WP` (`start`, `step(dt)`, `use(it)`, `noise`, `startPower`, `callRadio`, `G/P/M`); for logic tests stub `requestAnimationFrame` and use `waitForFunction(..., {polling: 500})`. Creature uses Lambert materials on purpose (Standard's specular made it look beige under the flashlight). Not hand-played; tuned only with headless scripted runs.
